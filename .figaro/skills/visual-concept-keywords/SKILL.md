# Visual Concept Keywords

Use these anchor keywords:

- caveman
- design
- ponytail

Related keywords:

- prehistoric

- leather
- fur
- stone-tools
- earthy-colors

## Workflow

1. Identify whether the request concerns character, costume, hairstyle, props, or environment.
2. Select only the keywords relevant to that request.
3. Combine them into one concise and visually coherent direction.
4. Describe silhouette, materials, colors, and one distinctive feature.
5. Avoid stereotypes or direct imitation of living cultures; use fictional or broad prehistoric references instead.

## Output

Return:

- a short concept title;
- 5–10 selected keywords;
- a concise visual description;
- optional variations when requested.
